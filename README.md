# Task Manager

A simple task management app with a Kanban-style board, built with vanilla JavaScript (ES6+), HTML and CSS. Users can add, edit, delete, search and move tasks between columns. All data is stored in the browser using `localStorage`.

## Features

- Kanban board with three columns: To Do, In Progress, Done
- Add, edit, delete and move tasks
- Set priority: High, Medium, Low
- Search and filter tasks
- Data saved in `localStorage`
- Fully responsive design

## Technologies

- HTML
- CSS
- Vanilla JavaScript (ES6+)
- localStorage
